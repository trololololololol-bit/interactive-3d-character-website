HOW TO RUN PROJECT:
1. Install visual studio code.
2. Open project folder.
3. Install the "Live Server" extension by Ritwick Dey
4. Right click the home.html file and click "Open with Live Server".
5. The project will run locally in the default browser. 


TROUBLESHOOTING - WIREFRAME BUTTON NOT WORKING:
If any of the buttons to interact with the model aren't working:

1. Click the "Reset" button.
2. Wait a few seconds and wait for the model to reload.
3. If the issue continues, refresh the page using the live server.
